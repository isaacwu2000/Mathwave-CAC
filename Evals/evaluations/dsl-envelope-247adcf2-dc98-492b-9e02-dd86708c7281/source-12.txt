export const programProtocol = `Math program API. Names separated by | share the following signature.
Use initialized const bindings, finite numeric arithmetic (+ - * / **), strings, arrays, explicit object properties and the approved calls. Imports, loops, functions, assignment, property reads, computed calls, casts and network access are unavailable.
Use <=${PROGRAM_LIMITS.characters} source characters, <=${PROGRAM_LIMITS.statements} statements and <=${PROGRAM_LIMITS.calls} calls per program. Bindings live within that program only. Call problem.save once for the final value to apply. Without save the program is read-only. A failed statement rejects the whole program. Preserve requested order and step boundaries.
A control must be the only call in its program. Queries return engine readbacks without saving temporary inputs. Never save only to answer a question.`;
