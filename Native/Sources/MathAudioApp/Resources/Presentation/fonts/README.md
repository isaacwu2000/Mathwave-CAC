# Self-hosted fonts

- Instrument Sans variable (400–700), from the official [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/instrumentsans). License: Instrument-Sans-OFL.txt.
- STIX Two Math, from the official [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/stixtwomath). License: STIX-OFL.txt.
- Legacy Lexend asset retained for existing saved references. License: OFL.txt.

Mathwave uses Instrument Sans for interface text and STIX Two Math for MathML. The structured math editor retains its bundled LaTeX math fonts.
